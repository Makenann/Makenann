# Hi, I'm Makenann
I'm a blind developer from Türkiye building accessible software, Android applications, and accessibility tools for mainstream games.
My work focuses on practical accessibility: giving blind users direct and independent access to software and experiences that are often designed primarily around visual interaction.
I build both standalone applications and accessibility layers for existing software, with screen-reader accessibility and nonvisual interaction treated as core design requirements rather than afterthoughts.
## Featured Projects
### ReadAccess
ReadAccess is an accessibility-first e-book reader for Android, designed especially for blind screen-reader users while retaining a clean reading experience for sighted readers.
It includes an integrated text-to-speech player, accessible book navigation, reading progress, bookmarks, full-book search, EPUB table-of-contents support, background playback, media controls, and extensive TTS customization.
ReadAccess currently supports TXT, EPUB, and text-based PDF books and is being prepared for release on Google Play.
The application is a proprietary project, while its public repository contains project information and documentation.
[Learn more about ReadAccess](https://github.com/Makenann/ReadAccess)
---
### WorldBoxAccess
WorldBoxAccess adds extensive screen-reader accessibility to WorldBox.
It provides nonvisual access to major game systems through keyboard navigation and spoken feedback, including world exploration, map navigation, powers, creatures, cities, kingdoms, saves, events, inspect systems, editors, and other gameplay interfaces.
The goal is not to replace the original game with a simplified accessible interface, but to expose the game's real systems so blind players can interact with them directly.
WorldBoxAccess is free and open source.
[View WorldBoxAccess](https://github.com/Makenann/WorldBoxAccess)
---
### FtlAccess
FtlAccess is a screen-reader accessibility mod for FTL: Faster Than Light.
It provides blind players with access to major gameplay systems including crew management, ship rooms and doors, weapons, targeting, combat information, stores, navigation, and other game state.
Like my other game-accessibility work, the project is designed around accessing the real mechanics of the original game rather than creating a separate simplified experience.
FtlAccess is free and open source.
[View FtlAccess](https://github.com/Makenann/FtlAccess)
## Accessibility-First Development
As a blind developer, I regularly work with development tools, interfaces, applications, and games that depend heavily on visual interaction.
That experience directly influences how I design software.
I care especially about:
* Screen-reader accessibility
* Efficient keyboard and nonvisual navigation
* Clear and useful spoken feedback
* Accessible state and context rather than visual-only information
* Interfaces that remain practical for both blind and sighted users
* Giving blind users access to the original functionality of software instead of unnecessarily reducing or simplifying it
For me, accessibility is not a checklist added at the end of development. It affects architecture, interaction design, navigation, testing, and the way information is presented from the beginning.
## AI-Assisted Development
AI coding tools are an important part of my development workflow.
I use them for tasks such as exploring unfamiliar codebases, understanding APIs and application behavior, investigating interfaces that are difficult to inspect nonvisually, debugging, prototyping, refactoring, and implementing accessibility features.
For a blind developer, these tools can provide more than a productivity improvement: they can reduce barriers in parts of software development that have traditionally depended heavily on visual tools and visual inspection.
I'm particularly interested in exploring how AI-assisted development can help make both software development itself and the software we build more accessible.
