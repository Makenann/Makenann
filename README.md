# Hi, I'm Makenann
I'm a blind developer from Türkiye focused on building accessible software for blind and visually impaired users.
I work on both standalone applications and accessibility layers for existing software and games. A major part of my development workflow is AI-assisted coding, which helps me work more independently with development environments and software systems that are often heavily visual.
## What I Build
My main focus is practical accessibility: building tools that give blind users direct, efficient access rather than simplifying or replacing the original experience.
### ReadAccess
ReadAccess is an accessibility-first e-book reader for Android designed for both blind and sighted readers.
It includes built-in text-to-speech and is being developed with independent, comfortable reading as a core design goal.
ReadAccess is currently in development for release on Google Play. Its source code is not publicly available at this time.
### WorldBoxAccess
WorldBoxAccess adds extensive screen-reader accessibility to WorldBox.
It provides keyboard-based world navigation, spoken game information, accessible menus and managers, map exploration, inspect systems, event history, scanner navigation, powers, saves, and access to major gameplay systems.
### FtlAccess
FtlAccess makes FTL: Faster Than Light playable with a screen reader while preserving the game's real mechanics and game state.
It provides access to menus, crew management, rooms and doors, weapons, targeting, combat feedback, stores, maps, ship systems, and other major gameplay systems.
## Accessibility and AI-Assisted Development
As a blind developer, I regularly work with software development environments and applications that were primarily designed around visual interaction.
AI coding tools have become an important part of my workflow. I use them to understand unfamiliar codebases, investigate visual interfaces and game systems, implement features, debug problems, and develop accessibility solutions more independently.
I'm particularly interested in using AI to reduce accessibility barriers in software development and to build tools that expand what blind users can independently do with mainstream software and games.
