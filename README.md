# Hi, I'm Makenann
I'm a blind developer from Türkiye building accessibility-first software and tools for blind users.
My work includes Android applications, screen-reader accessibility for mainstream games, text-to-speech systems, and nonvisual navigation.
I focus on giving blind users direct and independent access to software rather than creating unnecessarily simplified alternatives.
## Featured Projects
### ReadAccess
ReadAccess is an accessibility-first e-book reader for Android, designed especially for blind screen-reader users while remaining comfortable for sighted readers.
It includes built-in text-to-speech, TXT/EPUB/text-based PDF support, accessible navigation, bookmarks, search, reading progress, EPUB headings and table of contents, background playback, media controls, and extensive TTS customization.
ReadAccess is currently being prepared for release on Google Play.
[Learn more about ReadAccess](https://github.com/Makenann/ReadAccess)
### WorldBoxAccess
WorldBoxAccess adds extensive screen-reader accessibility to WorldBox.
It provides keyboard-based world exploration, spoken game information, accessible powers, map navigation, managers, inspect windows, events, saves, editors, and access to major gameplay systems.
[View WorldBoxAccess](https://github.com/Makenann/WorldBoxAccess)
### FtlAccess
FtlAccess provides screen-reader accessibility for FTL: Faster Than Light.
It gives blind players access to combat, targeting, crew management, rooms and doors, weapons, ship systems, stores, maps, events, and other major parts of the game.
[View FtlAccess](https://github.com/Makenann/FtlAccess)
## Accessibility and AI-Assisted Development
As a blind developer, I regularly work with development tools and software that depend heavily on visual interaction.
AI coding tools are an important part of my workflow. I use them to explore unfamiliar codebases, understand APIs and application behavior, debug problems, prototype ideas, and implement accessibility features.
For me, these tools provide more than a productivity improvement: they can reduce barriers in parts of software development that traditionally rely heavily on visual interfaces and visual inspection.
I'm particularly interested in using AI to make both software development itself and the software we build more accessible.
